# Localized hero recordings

The owner supplied `hero-loop (1).mp4` (Italian) and `hero-loop.en.mp4` (English) on 2026-10-14. Both are silent H.264 recordings, 1920 × 1080, 30 fps, 25 seconds. Their on-screen case and values are identified as demo/simulated material.

The originals are copied unchanged to `public/product-clips/hero-loop-v2.it.mp4` and `hero-loop-v2.en.mp4`. Versioned URLs avoid reusing cached media from the previous hero release.

Each language uses a first-frame poster extracted with FFmpeg and responsive WebP variants generated by the existing Vite image pipeline. Text alternatives cover the five scenes: sources/model, activity evidence, AS-IS simulation, TO-BE comparison and client sharing. Demo metrics are not represented as guaranteed outcomes.

Inline playback and the full-video dialog select the same localized MP4 and VTT. The old hero WebM is never a fallback for these recordings. Mobile retains the full 16:9 composition; the previous crop was designed for another recording. Reduced motion, Save-Data, pause/resume, off-screen loading and keyboard dialog controls retain their existing behavior.

Regression coverage: `e2e/product-films.spec.ts` checks IT → EN inline playback, direct English entry, EN → IT poster/dialog selection, full-HD metadata, 25-second duration, keyboard focus restoration and the absence of the obsolete mobile crop. The automatic main pipeline builds and publishes the tested frontend to IONOS.
