The comparison is a normal visible section, with no outer disclosure. Column order is DeliR, LucidFlow, PRIME BPM, Bizagi, Visio, Miro, ChatGPT/Claude. The diagram demo explainer remains an optional inner disclosure; the actual comparison table is always readable.

Public documentation was consulted on 21 October 2026. The former owner-supplied binary matrix is superseded by this request. Ratings now distinguish documented coverage, partial/manual coverage and unverified scope. Unverified is not evidence of absence.
