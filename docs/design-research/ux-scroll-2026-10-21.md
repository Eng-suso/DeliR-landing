## DeliR design decisions

The `ui-ux-pro-max` design-system query was used as a starting recommendation, not as an automatic design. Its suggestions for horizontal tracks, certificate badges, logo carousels and replacement fonts do not fit the existing product evidence or reading task. DeliR retains Hanken Grotesk, warm paper, navy and its own blue action color.

- A compact four-link index replaces a second feature-heading/grid after the hero. The hero checklist is removed; its benefits remain in the product chapters. Its static cover now shows the actual BPMN/evidence interface, replacing the floating document-tile introduction; explicit playback retains the existing localized film.
- The dark problem chapter uses a numbered reading sequence with a desktop sticky introduction, rather than four separate feature tiles.
- Main product chapters introduce the meaning first, then show an application screen across the available content width. Responsive poster sizes match the larger media slot. Extra screen borders, shadows, nested output rules and scene-number chips are removed.
- Scene choices remain real links with underlines and 48px touch targets. FAQ/disclosure controls use simple open/close marks. Language choices use text and an active underline rather than filled capsules.
- Mobile has a 44px quick waitlist action in the main navigation. A small, aria-hidden progress line and active product links reflect actual reading position.

## Scroll and motion implementation

The document remains the scroll container. No Lenis instance, wheel interception, pinned scroll track or new animation dependency is introduced for V2.

V2 same-document links are handled once before native anchor movement: the router updates history, fragment subscribers update, containing disclosures open, and the target receives focus with `preventScroll`. Repeated activation of the same anchor repositions the view without adding a duplicate history entry. The document destination uses the target’s layout-offset chain and computed scroll margin. Layout coordinates keep entrance transforms and the in-flight viewport position out of the absolute destination calculation. Font-driven layout changes retarget only when the destination actually changes. Font correction cannot repeatedly steal focus and is cancelled by new input or focus movement. Direct/history restoration is immediate; user navigation is smooth only when reduced motion is off.

The product index reads all three chapter positions together in one scheduled frame, rather than selecting whichever intersection callback happened to arrive first. Header/progress updates are coalesced with requestAnimationFrame and passive scroll listeners; observers/listeners are cleaned up on unmount. V2 disables inherited content-visibility height estimates and inherited competing scroll animations to avoid section jumps and stacked transforms.

Motion tokens are original DeliR choices: 220ms for control feedback, 560ms for one-time grouped entrance, a decelerating `cubic-bezier(.22,1,.36,1)`, and 70/140ms hero-copy offsets. Entrances use opacity/transform only, retain readable HTML before JavaScript, skip linked/focused content and respect reduced motion/Save-Data. FAQ rows do not each receive a separate entrance. Reduced motion removes transitions and entrance animation while retaining navigation and playback controls.
